# Part I. Lecture 1 — Catalan numbers

## 1. Catalan number 先從 Dyck path 定義

Lecture 1 一開始把 \(C_n\) 定義為一類長度 \(2n\) 的序列數目。

考慮

\[
(e_1,e_2,\ldots,e_{2n}),
\]

其中

\[
e_i\in\{+1,-1\},
\]

並要求兩件事：

\[
e_1+\cdots+e_{2n}=0,
\]

以及對任何 prefix，

\[
e_1+\cdots+e_j\ge 0.
\]

把 \(+1\) 畫成 upward step、\(-1\) 畫成 downward step，就得到一條從 \((0,0)\) 出發、最後回到水平軸，而且中間永遠不掉到水平軸以下的路徑。

這就是 Dyck path。Lecture 1 用這個方式定義 Catalan numbers。:chatgpt-content-reference{index="1"}

前幾項是

\[
C_0=1,
\]

\[
C_1=1,
\]

\[
C_2=2,
\]

\[
C_3=5,
\]

\[
C_4=14,
\]

\[
C_5=42.
\]

Lecture 1 第二頁同時畫出小 \(n\) 的 Dyck paths。:chatgpt-content-reference{index="2"}

---

# 2. Catalan number 的另一個詮釋：polygon triangulation

Lecture 1 很快指出：

\[
\boxed{
C_n=
\#\{\text{triangulations of a convex }(n+2)\text{-gon}\}.
}
\]

triangulation 的意思是：

用彼此不交叉的 diagonals，把凸多邊形完全分割成三角形。

例如 pentagon 有

\[
5=C_3
\]

種 triangulations。

講義第二頁直接畫出了五邊形的五種 triangulation。:chatgpt-content-reference{index="3"}

所以此時已經有：

\[
\boxed{
\text{Dyck paths of length }2n
\quad\leftrightarrow\quad
\text{triangulations of }(n+2)\text{-gon}
}
\]

至少在「數量」上相同。

但 Lecture 1 此時還沒有真正建立 bijection，而是先證明兩者滿足同一 Catalan recurrence。

---

# 3. Catalan recurrence

Lecture 1 的核心做法是把一條 Dyck path 分解。

考慮一條非空 Dyck path。

它從

\[
(0,0)
\]

先走一步上升。

接著第一次重新回到 \(x\)-axis。

這個「第一次 return」把 path 分成兩個較小的 Dyck paths。

概念上是

\[
P
=
\uparrow
P_1
\downarrow
P_2.
\]

如果

\[
P_1
\]

有 \(2(k-1)\) steps，而剩下的

\[
P_2
\]

有 \(2(n-k)\) steps，那麼：

\[
P_1
\]

有

\[
C_{k-1}
\]

種，

而

\[
P_2
\]

有

\[
C_{n-k}
\]

種。

兩者可以獨立選擇，因此固定 \(k\) 有

\[
C_{k-1}C_{n-k}
\]

種。

最後把所有可能的 \(k\) 加起來：

\[
\boxed{
C_n
=
\sum_{k=1}^{n}
C_{k-1}C_{n-k}.
}
\]

等價寫法是

\[
\boxed{
C_n
=
\sum_{k=0}^{n-1}
C_kC_{n-1-k}.
}
\]

Lecture 1 第四頁就是這個 decomposition 與 recurrence。:chatgpt-content-reference{index="4"}

這裡第一次出現 Catalan 世界裡最重要的結構：

\[
\boxed{
\text{one object}
\rightarrow
\text{two independent smaller Catalan objects}.
}
\]

---

# 4. 從 recurrence 到 generating function

定義 ordinary generating function：

\[
C(x)
=
C_0+C_1x+C_2x^2+\cdots.
\]

也就是

\[
\boxed{
C(x)=\sum_{n\ge0}C_nx^n.
}
\]

利用 recurrence，

\[
C_n
=
\sum_{k=0}^{n-1}
C_kC_{n-1-k},
\]

Lecture 1 把它改寫成 generating-function equation：

\[
C(x)-1
=
xC(x)^2.
\]

所以

\[
\boxed{
C(x)=1+xC(x)^2.
}
\]

Lecture 1 第五頁明確寫出這個 equation。:chatgpt-content-reference{index="5"}

這一步本質上就是 Cauchy product：

\[
C(x)^2
=
\sum_{n\ge0}
\left(
\sum_{k=0}^{n}
C_kC_{n-k}
\right)x^n.
\]

因此：

\[
\boxed{
\text{combinatorial independent product}
\leftrightarrow
\text{multiplication of generating functions}.
}
\]

這一點對你之後讀 Chu 最重要。

---

# 5. 解 generating-function equation

由

\[
C=1+xC^2
\]

得到

\[
xC^2-C+1=0.
\]

把 \(C\) 當未知數，用 quadratic formula：

\[
C(x)
=
\frac{1\pm\sqrt{1-4x}}{2x}.
\]

因為 generating function 必須滿足

\[
C(0)=1,
\]

所以選擇：

\[
\boxed{
C(x)
=
\frac{1-\sqrt{1-4x}}{2x}.
}
\]

這是 Lecture 1 第六頁的結果。:chatgpt-content-reference{index="6"}

---

# 6. 從 generating function 得到 closed form

Lecture 1 接著利用 generalized binomial expansion 展開

\[
\sqrt{1-4x}.
\]

最後得到：

\[
\boxed{
C_n
=
\frac1{n+1}
\binom{2n}{n}.
}
\]

這就是 Catalan number 的 closed form。Lecture 1 第七、八頁完成這個 derivation。:chatgpt-content-reference{index="7"}

一個 drunkard 在整數線上做 symmetric random walk：

每一步：

\[
+1

或

\[
-1

各以 probability

\[
\frac12

發生。

問題是：

# 9. Catalan number 的第二種證明：reflection principle

Lecture 2 接著回到 Catalan numbers。

考慮所有從

\[
(0,0)
\]

走到

\[
(2n,0)
\]

的 lattice paths。

每一步是

\[
(1,+1)
\]

或

\[
(1,-1).
\]

要回到零，所以一定需要：

\[
n\text{ up steps}
\]

和

\[
n\text{ down steps}.
\]

因此總路徑數為

\[
\boxed{
\binom{2n}{n}.
}
\]

我們真正想要的是 Dyck paths，也就是從不低於 \(y=0\) 的 paths。

所以：

\[
\text{good paths}
=
\text{all paths}
-
\text{bad paths}.
\]

Lecture 2 把 bad path 定義為至少碰到

\[
y=-1
\]

的 path。

取 bad path 第一次碰到 \(y=-1\) 的點 \(A\)，把從起點到 \(A\) 的那一段對直線

\[
y=-1
\]

反射。

這會建立一個 bijection：

\[
\boxed{
\text{bad paths from }(0,0)\text{ to }(2n,0)
}
\]

和

\[
\boxed{
\text{all paths from }(0,-2)\text{ to }(2n,0)
}
\]

之間。

Lecture 2 第六到八頁完整畫出這個 reflection map。:chatgpt-content-reference{index="10"}

後者需要：

\[
n+1\text{ up steps}
\]

與

\[
n-1\text{ down steps}.
\]

因此 bad paths 有

\[
\binom{2n}{n-1}
\]

條。

所以：

\[
C_n
=
\binom{2n}{n}
-
\binom{2n}{n-1}.
\]

整理：

\[
\boxed{
C_n
=
\frac1{n+1}
\binom{2n}{n}.
}
\]

# 10. 第三種證明：cyclic shifts

Lecture 2 還提供另一個非常典型的 Catalan proof：cyclic shift / cycle lemma style argument。

它考慮一個包含某種固定數量 \(+1\) 和 \(-1\) 的 sequence，然後考察它的所有 cyclic rotations。

不同 rotation 之間對「partial sums 始終符合某條件」的性質會產生固定比例。

這最後又導向：

\[
\boxed{
C_n
=
\frac{1}{n+1}\binom{2n}{n}.
}
\]

Lecture 2 第九、十頁是在發展這個 cyclic-shift proof。:chatgpt-content-reference{index="11"}

這個思想與你後來 Chu 講義裡加入的 **Raney / cycle lemma** 是同一類方法，非常值得保留。

# 12. Plane trees

Lecture 3 首先增加 Catalan interpretation：

\[
\boxed{
C_n=
\#\{\text{plane trees with }n+1\text{ vertices}\}.
}
\]

plane tree 的重點是：

children 有平面排列順序。

也就是

\[
\text{left child}
\neq
\text{right child}.
\]

Lecture 3 第一頁畫出 \(n=3\) 時的五棵 plane trees。:chatgpt-content-reference{index="14"}

# 13. Noncrossing matchings

Lecture 3 接著引入：

\[
\boxed{
\text{non-crossing arc diagrams}
}
\]

也稱：

\[
\boxed{
\text{non-crossing matchings}.
}
\]

在 \(2n\) 個線性排列的 vertices 上，把它們兩兩配對。

每一 pair 用一條 arc 連起來。

要求 arcs 不允許 crossing。

例如 arcs

\[
(i,k)
\]

和

\[
(j,l)
\]

如果

\[
i<j<k<l,
\]

就發生 crossing。

Lecture 3 第二頁也畫出 crossing 與 noncrossing 的例子。:chatgpt-content-reference{index="15"}

這個集合的大小也是：

\[
\boxed{C_n}.
\]

---

# 14. Nonnesting arc diagrams

Lecture 3 同一頁還介紹另一個 Catalan family：

\[
\boxed{
\text{non-nesting arc diagrams}.
}
\]

noncrossing 禁止：

\[
i<j<k<l
\]

形成

\[
(i,k),(j,l).
\]

nonnesting 則禁止一條 arc 完全包含另一條：

\[
i<j<k<l,
\]

並有

\[
(i,l),(j,k).
\]

Lecture 3 特別指出：

> noncrossing 和 nonnesting 的這種 duality 是 Catalan world 裡常見現象。

:chatgpt-content-reference{index="16"}

# 15. Triangulation ↔ complete plane binary tree

Lecture 3 建立第一個重要 bijection：

\[
\boxed{
\text{triangulations of }(n+2)\text{-gon}
\longleftrightarrow
\text{complete plane binary trees}.
}
\]

方法是取 triangulation 的 planar dual graph。

把每一個 triangle 當作一個 vertex。

兩個 triangles 共用 diagonal，就連一條 edge。

再在 polygon boundary 的適當位置加入 leaves / root information。

最後得到一棵 plane binary tree。

Lecture 3 第三頁直接畫出 triangulated polygon 和其 dual binary tree。:chatgpt-content-reference{index="17"}

這非常重要，因為它證明：

\[
\text{triangulation}
\]

和

\[
\text{binary tree}
\]

不只是數量剛好都是 Catalan，它們有結構上的一一對應。

# 16. Plane tree ↔ Dyck path

Lecture 3 下一個 bijection：

\[
\boxed{
\text{plane trees with }n+1\text{ vertices}
\longleftrightarrow
\text{Dyck paths with }2n\text{ steps}.
}
\]

做法是沿著 tree 進行 depth-first traversal。

當你沿著一條 edge：

第一次離開 parent 往 child：

\[
\text{up step}.
\]

從 child 回到 parent：

\[
\text{down step}.
\]

每條 edge 正好 traversal 兩次。

一棵有 \(n\) 條 edges 的 tree，就產生 \(2n\) steps。

Lecture 3 第四頁把 traversal path 直接變形成 Dyck path。:chatgpt-content-reference{index="18"}

---

# 17. Dyck path ↔ noncrossing matching

這是對 Chu 最重要的 bijection。

取一條 Dyck path。

每一個 up-step 最終都有與之配對的 down-step。

把這一 pair 對應到 arc diagram 中的兩個 positions。

也就是：

\[
\boxed{
\text{matched up/down steps}
\longleftrightarrow
\text{arc}.
}
\]

因為 Dyck path 的括號式 nesting 結構不會產生交叉配對，所以得到 noncrossing matching。

反過來，也可以從 noncrossing arc diagram 恢復 Dyck path。

因此：

\[
\boxed{
\text{Dyck paths}
\longleftrightarrow
\text{noncrossing matchings}.
}
\]

Lecture 3 第五頁完整畫出這個 transformation。:chatgpt-content-reference{index="19"}

到這裡，我們已經有一條完整 chain：

\[
\boxed{
\text{triangulation}
\leftrightarrow
\text{binary tree}
\leftrightarrow
\text{Dyck path}
\leftrightarrow
\text{noncrossing matching}.
}
\]

# 20. Pattern avoidance

Lecture 3 接著正式定義 permutation pattern。

假設：

\[
w=w_1\cdots w_n
\]

是一個 permutation。

另一個較短 permutation：

\[
\pi=\pi_1\cdots\pi_k.
\]

如果可以在 \(w\) 中找到位置：

\[
i_1<i_2<\cdots<i_k
\]

使得

\[
w_{i_1},\ldots,w_{i_k}
\]

之間的相對大小關係與

\[
\pi_1,\ldots,\pi_k
\]

完全相同，就說：

\[
w
\]

contains pattern \(\pi\)。

否則叫：

\[
\pi\text{-avoiding}.
\]

Lecture 3 的重點 pattern 是：

\[
231.
\]

:chatgpt-content-reference{index="22"}

# 22. Integer partitions

Lecture 3 最後轉入另一個不同意義的 partition。

這裡的 partition 不是 Chu 的 set partition。

Lecture 3 定義：

\[
\lambda=(\lambda_1,\lambda_2,\ldots,\lambda_k)
\]

是 \(n\) 的一個 integer partition，如果：

\[
\lambda_1+\cdots+\lambda_k=n
\]

且

\[
\lambda_1\ge\lambda_2\ge\cdots\ge\lambda_k>0.
\]

例如：

\[
5=3+2
\]

和

\[
5=2+3
\]

在 integer partition 裡是同一個 partition，因為 parts 依 decreasing order 排列。

如果順序重要，則叫 composition。

Lecture 3 第十二頁明確區分 partitions 與 compositions。:chatgpt-content-reference{index="24"}

# 23. Young diagrams

一個 integer partition：

\[
\lambda=(\lambda_1,\ldots,\lambda_k)
\]

可以畫成 Young diagram。

第 \(i\) row 有：

\[
\lambda_i
\]

個 boxes。

例如：

\[
\lambda=(5,3,3,2,1).
\]

就是第一 row 5 boxes，第二 row 3 boxes，等等。

Lecture 3 第十三頁開始用 Young diagram 表示 partitions。:chatgpt-content-reference{index="25"}

# 24. Standard Young tableau

給一個 Young diagram \(\lambda\)。

把數字：

\[
1,2,\ldots,n
\]

放入所有 boxes。

如果：

每一 row 左到右嚴格增加；

每一 column 上到下嚴格增加，

則得到：

\[
\boxed{\text{standard Young tableau (SYT)}}.
\]

Lecture 3 最後開始問：

\[
f^\lambda
=
\#\{\text{SYT of shape }\lambda\}
\]

怎麼計算。:chatgpt-content-reference{index="26"}

# 27. SYT \((n,n)\) ↔ Dyck path

Lecture 4 建立一個很漂亮的 bijection。

給一個 SYT：

\[
T
\]

of shape

\[
(n,n).
\]

讀取數字：

\[
1,2,\ldots,2n.
\]

如果數字 \(i\) 位於第一 row，就令第 \(i\) step 是：

\[
\text{up step}.
\]

如果位於第二 row，就令第 \(i\) step 是：

\[
\text{down step}.
\]

因為 tableau 的 column-increasing condition，形成的 path 不會掉到 axis 以下。

因此得到 Dyck path。

所以：

\[
\boxed{
\text{SYT of shape }(n,n)
\longleftrightarrow
\text{Dyck paths of length }2n.
}
\]

Lecture 4 第二頁直接畫出這個 correspondence。:chatgpt-content-reference{index="29"}

# 28. Generalized Dyck paths 與 arbitrary shape

Lecture 4 接著把這件事 generalize。

對 shape：

\[
\lambda=(\lambda_1,\ldots,\lambda_k),
\]

可以把 SYT 轉換成 \(k\)-dimensional lattice path。

每一 row 對應一個 coordinate direction：

\[
e_1,e_2,\ldots,e_k.
\]

若 number \(i\) 在 row \(r\)，第 \(i\) step 就走：

\[
e_r.
\]

tableau 的 row/column conditions 轉換成 path staying in a Weyl-chamber-like region。

Lecture 4 第三頁畫了這個 generalized Catalan / generalized Dyck-path viewpoint。:chatgpt-content-reference{index="30"}

# 29. Hook of a box

Lecture 4 接著定義 hook。

對 Young diagram 中的一個 box \(c\)：

hook 包含：

- \(c\) 本身；
- \(c\) 右邊同 row 的 boxes；
- \(c\) 下方同 column 的 boxes。

hook length：

\[
\boxed{h(c)}
\]

就是 hook 中 boxes 的數目。

Lecture 4 第四頁畫出 hook 的形狀。:chatgpt-content-reference{index="31"}

---

# 30. Hook-length formula

Lecture 4 的核心 theorem：

如果

\[
|\lambda|=n,
\]

那麼：

\[
\boxed{
f^\lambda
=
\frac{n!}
{\prod_{c\in\lambda}h(c)}.
}
\]

這就是 Frame–Robinson–Thrall hook-length formula。

Lecture 4 第四頁正式給出。:chatgpt-content-reference{index="32"}

例如對某個 shape，只要把所有 boxes 的 hook lengths 乘起來，再用 \(n!\) 除掉，就得到 SYT 數目。

---

# 31. Hook-length recurrence

在證明 hook-length formula 前，Lecture 4 先利用 SYT 的最大數字 \(n\)。

在一個 SYT 裡：

\[
n
\]

一定放在一個 corner box。

因為如果右邊或下面還有 box，就會需要更大的數字。

所以移除 containing-\(n\) 的 corner \(c\)，剩下一個 shape：

\[
\lambda-c.
\]

因此：

\[
\boxed{
f^\lambda
=
\sum_{c\text{ corner}}
f^{\lambda-c}.
}
\]

Lecture 4 第五頁用這個 recurrence 作為 hook-length proof 的起點。:chatgpt-content-reference{index="33"}

---

# 32. 要證明 hook-length formula，只需要驗證 recurrence

如果假設：

\[
f^\lambda
=
\frac{n!}{H(\lambda)},
\]

其中

\[
H(\lambda)
=
\prod_{c\in\lambda}h(c),
\]

那麼 recurrence 要求：

\[
\frac{n!}{H(\lambda)}
=
\sum_{c\text{ corner}}
\frac{(n-1)!}{H(\lambda-c)}.
\]

除以 \((n-1)!\)：

\[
\boxed{
\sum_{c\text{ corner}}
\frac1n
\frac{H(\lambda)}{H(\lambda-c)}
=
1.
}
\]

Lecture 4 第六頁把問題化成這個 probability-like identity。:chatgpt-content-reference{index="34"}

這就是接下來 hook walk 的動機。

---

# 33. Hook walk

Lecture 4 的證明採用 probabilistic hook walk。

從 Young diagram 中隨機選一個起始 box。

然後：

如果目前 box 是 \(a\)，就隨機跳到它 hook 中右方或下方的另一個 box。

一直走。

因為每一步都往右或往下，所以最後必然停在一個 corner。

Lecture 4 第八頁畫出 hook walk 的規則。:chatgpt-content-reference{index="35"}

---

# 34. Corner probability

令：

\[
P(c)
\]

表示 hook walk 最後停在 corner \(c\) 的 probability。

因為一定停在某個 corner：

\[
\boxed{
\sum_{c\text{ corner}}P(c)=1.
}
\]

Lecture 4 的目標是證明：

\[
\boxed{
P(c)
=
\frac1n
\frac{H(\lambda)}{H(\lambda-c)}.
}
\]

一旦證明，對所有 corners 求和就是：

\[
\sum_c
\frac1n
\frac{H(\lambda)}{H(\lambda-c)}
=
1,
\]

正好完成 hook-length recurrence。

:chatgpt-content-reference{index="36"}

---

# 35. Hook walk 的 path weights

Lecture 4 把每一條 hook-walk path：

\[
P
\]

賦予 weight：

\[
\operatorname{wt}(P).
\]

一條特定 path 的 probability，就是沿途每一次 jump probability 的乘積。

因此：

\[
P(a,c)
=
\sum_{\substack{\text{hook walks}\\a\to c}}
\operatorname{wt}(P).
\]

再對所有起點 \(a\) 平均，就得到：

\[
P(c).
\]

Lecture 4 第九到十三頁在詳細分析這些 weighted paths。:chatgpt-content-reference{index="37"}

---

# 36. 用矩形區域分解 hook walks

講義接著固定 corner \(c\)。

考察可以到達 \(c\) 的 boxes 所形成的 rectangle / co-hook-like region。

通過不同 rows 與 columns 的 hook-walk paths，可以利用一個 weighted lattice-path identity 做 summation。

Lecture 4 建立一個 lemma：

對某個矩形區域中的 monotone lattice paths，其 weight sum 會 collapse 成一個簡單 rational expression。

它利用 induction on rectangle dimensions 證明。:chatgpt-content-reference{index="38"}

---

# 37. Hook walk probability 化成 hook-length ratio

利用前面的 weighted-path lemma，Lecture 4 最終得到：

\[
P(c)
=
\frac1n
\prod_{b\in\text{co-hook}(c)}
\frac{h(b)}{h(b)-1}.
\]

但當 corner \(c\) 被刪除時，只有 \(c\) 同 row 左側與同 column 上方 boxes 的 hook lengths 會減 1。

因此：

\[
\prod_{b\in\text{co-hook}(c)}
\frac{h(b)}{h(b)-1}
=
\frac{H(\lambda)}{H(\lambda-c)}.
\]

所以：

\[
\boxed{
P(c)
=
\frac1n
\frac{H(\lambda)}{H(\lambda-c)}.
}
\]

Lecture 4 第十五、十六頁完成這一步。:chatgpt-content-reference{index="39"}

最後因為：

\[
\sum_cP(c)=1,
\]

得到 hook-length recurrence，因而完成 hook-length formula 的 induction proof。:chatgpt-content-reference{index="40"}

# 四堂課的核心結構

如果把四堂課壓縮成一張理論地圖，就是：

\[
\boxed{
\begin{array}{c}
\text{Dyck paths}
\\[1mm]
\downarrow
\\
C_n=\sum C_kC_{n-1-k}
\\
\downarrow
\\
C(x)=1+xC(x)^2
\\
\downarrow
\\
C(x)=\frac{1-\sqrt{1-4x}}{2x}
\\
\downarrow
\\
C_n=\frac1{n+1}\binom{2n}{n}
\end{array}}
\]

同時有一大片 Catalan bijection network：

\[
\boxed{
\begin{array}{ccccc}
\text{triangulations}
&\leftrightarrow&
\text{binary trees}
&\leftrightarrow&
\text{Dyck paths}
\\[2mm]
&&&&\updownarrow
\\[-1mm]
&&&&
\text{noncrossing matchings}
\\[2mm]
&&&&\updownarrow
\\[-1mm]
&&&&
\text{balanced parenthesis structures}
\end{array}}
\]

還有另一條：

\[
\boxed{
\text{stack-sortable permutations}
=
231\text{-avoiding permutations}
}

也由 Catalan numbers 計數。

再往 representation combinatorics：

\[
\boxed{
\text{integer partitions}
\rightarrow

\text{SYT}
}

並且：

\boxed{
C_n

最後一般 shape：

\boxed{

\frac{|\lambda|!}
{\prod_{c\in\lambda}h(c)}

由 hook walk 完成證明。

# 與 Chu paper 的關係

四堂課裡，跟 Chu 最直接的部分是：

\[
\boxed{
\text{Dyck path}
\leftrightarrow
\text{noncrossing matching}
}
\]

以及普通 Catalan 的 recursive equation：

\[
\boxed{
C=1+xC^2.
}
\]

Chu 的 generalization 可以看成把：

\[
\text{every block has size }2
\]

改成：

\[
\text{block can have prescribed sizes }v_i.
\]

普通 Catalan root object 產生兩個 subproblems：

\[
C^2.
\]

Chu 的 \(v_i\)-point group 產生：

\[
v_i
\]

個 subproblems，所以：

\[
D^{v_i}.
\]

因此：

\[
\boxed{
C=1+xC^2
}
\]

自然變成

\[
\boxed{
D
=
1+\sum_i x_iD^{v_i}.
}
\]

這也是為什麼這四堂 Lecture 很適合放在你的 Chu 動畫前面：它們不是無關的 Catalan trivia，而是在建立 Chu 所需要的整個 combinatorial language。

另外有一個要特別記住的 terminology：

Lecture 3–4 的

\[
\boxed{\text{partition}}
\]

主要是 **integer partition**

\[
\lambda=(\lambda_1,\lambda_2,\ldots),
\]

而 Chu 的

\[
\boxed{\text{partition}}
\]

是 **set partition into blocks**。

這兩個是不同概念。這四堂講義本身並沒有完整發展 Chu 所需的 general **noncrossing set partition** 理論；那一塊仍然需要另外補。:chatgpt-content-reference{index="41"}
