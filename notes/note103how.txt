# NEW M03 — `CatalanCauchyProduct`

這幕是**新增內容裡最重要的一幕**。

因為現有 Scene07 有：

\[
D=1+\sum_i x_iD^{v_i},
\]

但還缺「為什麼 generating functions 的乘法代表 independent subproblems」。

要真的動畫化 Cauchy product：

\[
C(x)
=
C_0+C_1x+C_2x^2+\cdots.
\]

兩份 \(C(x)\) 相乘。

例如：

\[
[x^2]C(x)^2
=
C_0C_2+C_1C_1+C_2C_0.
\]

用 diagonal convolution 動畫。

最後：

\[
[x^n]C^2
=
\sum_{k=0}^{n}C_kC_{n-k}.
\]

因此：

\[
C(x)-1=xC(x)^2
\]

↓

\[
\boxed{
C=1+xC^2.
}
\]

Lecture 1 正是在 recurrence 之後得到這條 generating-function equation。:chatgpt-content-reference{index="5"}

**注意：**

這裡是「推導普通 Catalan equation」。

之後 Scene07 不再重新推導，而只說：

\[
C=1+xC^2
\]

是我們之前已經理解的 ordinary case。

# NEW M16 — `HookLengthAndCornerRecurrence`

合併三件事：

### Hook

選 box \(c\)。

highlight：

- 自己；
- 右側；
- 下側。

得到：

\[
h(c).
\]

### Hook-length formula

\[
H(\lambda)
=
\prod_ch(c),
\]

\[
\boxed{
f^\lambda
=
\frac{n!}{H(\lambda)}
}.
\]

### Corner recurrence

最大數字 \(n\) 必在 corner。

移掉它：

\[
\boxed{
f^\lambda
=
\sum_{c\text{ corner}}
f^{\lambda-c}.
}
\]

再把證明目標 reduce 成：

\[
\boxed{
\sum_c
\frac1n
\frac{H(\lambda)}{H(\lambda-c)}
=1.
}
\]

Lecture 4 正是這個順序。:chatgpt-content-reference{index="20"}
