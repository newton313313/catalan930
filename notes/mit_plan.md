## 3. 貫穿的例子（全部由 counting.py 算出，場景裡要 assert）
`EX = binary_trees(3)[3] = ((None,(None,None)),None)`（00k 第 4 欄，C_2C_0）
- 括號：(a·(b·c))·d；Dyck：UUDUDD；開票：AABABB；括號字串：(()())
- 三角剖分（五邊形頂點 0..4，底邊 0–4）：對角線 0 起算 (0,3),(1,3) → 標成 1..5 是 {1,4},{2,4}
- 對偶二元樹 = EX（三角形=內部節點，非底邊的多邊形邊=葉子，含底邊的三角形=根）
- 平面樹（左小孩=第一個小孩、右小孩=下一個兄弟）：根 → A → 兩片葉子；DFS 得 UUDUDD
- 配對（1 起算）：(1,6),(2,3),(4,5)；SYT (3,3)：第一列 {1,2,4}、第二列 {3,5,6}

## 4. 新場景規格（檔名 `codes/scenes/sceneMxx_*.py`，類別 `SceneMxx…`，字幕繁中）
長度是建議值。每幕開頭 `show_header(…)`，結尾留 1–2 秒。

**M01 `sceneM01_cauchy_product.py` / `SceneM01CauchyProduct`（L1，~45s）**
C(x)=C_0+C_1x+C_2x²+… 寫成乘法表的列與行（4×4，格 (i,j)=C_iC_j x^{i+j}）；依序亮反對角線 i+j=n：
[x²]C² = C_0C_2+C_1C_1+C_2C_0 = 2+1+2 = 5；一般 [xⁿ]C² = Σ_{k=0}^{n} C_kC_{n−k}。
對照遞迴 C_{n+1}=Σ_{k=0}^{n}C_kC_{n−k} = [xⁿ]C² → C−1 = xC² → C = 1+xC²。用青／粉紅標出「左 C_k、右 C_{n−k}」（獨立 → 相乘）。

**M02 `sceneM02_closed_form.py` / `SceneM02ClosedForm`（L1，~45s）**
xC²−C+1=0 → C=(1±√(1−4x))/(2x)；x→0 時「+」≈1/x 爆掉，「−」→1=C_0 → 取減號。
二項級數：√(1−4x)=Σ binom(1/2,m)(−4x)^m，binom(1/2,m)(−4)^m = −(2/m)·binom(2m−2,m−1)；
√(1−4x)=1−2x−2x²−4x³−10x⁴−…；代回得 C_n=(1/(n+1))binom(2n,n)，前幾項 1,1,2,5,14。

**M03 `sceneM03_drunkards_walk.py` / `SceneM03DrunkardsWalk`（L1–2，~50s）**
數線上醉漢從 0 出發，每步 ±1 各 1/2，走到 −1（懸崖）就掉下去。時間–位置圖：第 2n+1 步第一次掉下去 ⇔ 前 2n 步是 Dyck 路徑＋一步往下 → C_n 條，機率 C_n/2^{2n+1}。
例：n=0：D（1/2）；n=1：UDD（1/8）；n=2：兩條（2/32）。總和 Σ C_n/2^{2n+1} = (1/2)C(1/4) = (1/2)·2 = 1（用 M02 的閉式，x=1/4 時根號為 0）。
部分和 1/2, 5/8, 11/16, … 慢慢趨近 1。

**M04 `sceneM04_cyclic_shift.py` / `SceneM04CyclicShift`（L2，~45s）**
古典循環引理：n+1 個 +1、n 個 −1（總和 +1，長度 2n+1）的序列，2n+1 種循環讀法中恰有 1 種「出發後前綴和都 >0」。
取 n=3（長度 7）的一個不好的序列，列出 7 種循環讀法（沿用 `utils/lattice_paths.py` 的 `PathMob`／`path_thumbnail`，v=(2,)：字母 0=+1、1=−1），標出唯一好的。
計數：binom(7,3)=35 條，每 7 條一組、每組恰 1 條好 → 35/7=5=C_3；好的序列 = 一個 +1 接一條 Dyck 路徑 → C_n = binom(2n+1,n)/(2n+1) = (1/(n+1))binom(2n,n)。
結尾預告：「第 8 場景的 Raney 公式，把同樣的想法推廣到多種步長。」

**M05 `sceneM05_plane_trees.py` / `SceneM05PlaneTrees`（L3，~40s）**
平面樹：有根、小孩有左右順序；同一棵抽象樹交換小孩 → 不同的平面樹（4 個頂點的例子）。
n+1 個頂點的平面樹有 C_n 棵：n=0..3 為 1,1,2,5，列出 n=3 的 5 棵（順序 = binary_trees(3) 經「左小孩=第一個小孩、右小孩=下一個兄弟」轉換，與 00k 欄位一致）。

**M06 `sceneM06_arc_diagrams.py` / `SceneM06ArcDiagrams`（L3，~45s）**
圓上 6 點的配對 (1,6),(2,3),(4,5)（和 00j／Scene01 同一種畫法）→ 在點 6 與點 1 之間剪開，攤平成直線 1..6，弦變成上方的弧。
直線上的條件：(i,k),(j,l) 且 i<j<k<l → 交叉（紅）；(i,l),(j,k) 且 i<j<k<l → 巢狀。
6 點的完美配對共 15 種：不交叉 5 種、不巢狀 5 種，兩排並列；(1,2),(3,4),(5,6) 兩者都是。

**M07 `sceneM07_triangulation_dual_tree.py` / `SceneM07TriangulationDualTree`（L3，~50s）**
第 3 節的五邊形三角剖分 → 每個三角形中心放節點、共用對角線連邊、每條非底邊的多邊形邊外放一片葉子、含底邊的三角形是根 → 多邊形淡出，留下完全二元樹，再整理成 `catalan_draw.BinaryTreeMob` 的標準畫法（根／左／右上色）。
接著：二元樹 → 平面樹（左小孩=第一個小孩、右小孩=下一個兄弟），得到 M05 列表中同一棵。

**M08 `sceneM08_tree_dyck_matching.py` / `SceneM08TreeDyckMatching`（L3，~50s）**
M07 的平面樹：一個點沿樹的輪廓走（DFS），往下記 U、往上記 D，下方同步長出 Dyck 路徑 UUDUDD。
每個 U 與它配對的 D 連弧 → (1,6),(2,3),(4,5)；弧圖收回成圓上的配對（M06 的反向）。
結尾一條鏈：三角剖分 ↔ 二元樹 ↔ 平面樹 ↔ Dyck ↔ 不交叉配對。

**M09 `sceneM09_stack_queue_sorting.py` / `SceneM09StackQueueSorting`（L3，~60s）**
堆疊（後進先出）：輸入 → 堆疊 → 輸出，目標輸出 1,2,…,n；規則：堆疊頂端正好是下一個要輸出的就彈出，否則把下一個輸入推入；輸入用完而頂端不對 → 失敗。
示範一個可排序的例子（長度 4–5，由程式確認）與 231 失敗。
佇列＋插隊線（第 1 節第 5 點的規則）：231 可以、321 失敗。
結果：堆疊可排序 ⇔ 避開 231；佇列＋插隊線可排序 ⇔ 避開 321；個數都是 C_n（n=3：5、n=4：14）。

**M10 `sceneM10_pattern_avoidance.py` / `SceneM10PatternAvoidance`（L3，~45s）**
定義：w 含模式 π ⇔ 有子序列與 π 的相對大小相同。例：41532 的 4,5,3 → 231；再給一個避開 231 的例子（程式確認）。
n=3：6 個排列中 5 個避開 231；n=4：24 個中 14 個（格狀列出、標色）。
定理：堆疊可排序 ⇔ 避開 231；避開任一個長度 3 的模式都恰有 C_n 個（6 個模式的計數表 n≤6，由程式算）。

**M11 `sceneM11_partitions_young.py` / `SceneM11PartitionsYoung`（L3，~50s）**
整數分割 λ⊢n（λ₁≥λ₂≥…>0）；5 的 7 個分割；(3,2) 是分割，(2,3) 只是合成（5 的合成有 16 個）。
警告框：整數分割 ≠ Chu 的集合分割（把點分成區塊）。
Young 圖（英式：列靠左、由上往下變短）：(5,3,3,2,1)。SYT：列 →、行 ↓ 都遞增；列出 (3,2) 的 5 個 SYT，f^{(3,2)}=5。

**M12 `sceneM12_syt_dyck.py` / `SceneM12SYTDyck`（L4，~45s）**
形狀 (3,3)：依序讀 1..6，在第一列 → U、第二列 → D（行遞增 ⇒ 前綴 U 數 ≥ D 數 ⇒ Dyck）；先逐步轉換第 3 節的 [[1,2,4],[3,5,6]] → UUDUDD，再並列全部 5 對。f^{(n,n)}=C_n。
一般 λ=(λ₁,…,λ_k)：i 在第 r 列 → 走 e_r；條件 = 走到任何時候都有 x₁≥x₂≥…≥x_k（用一個 3 列的小例子、累計次數表示，不必畫 3D）。

**M13 `sceneM13_hook_length.py` / `SceneM13HookLength`（L4，~55s）**
鉤：格子本身＋同列右邊（arm）＋同行下面（leg）；h=arm+leg+1。λ=(4,3,1) 的鉤長 6,4,3,1 / 4,2,1 / 1，乘積 576，8!/576=70=f^λ。
鉤長公式 f^λ=n!/∏h(c)。驗算 (3,2)：120/24=5（接 M11）；(3,3)：720/144=5=C_3；一般 (n,n)：∏h=(n+1)!n! → C_n。
角落遞迴：最大的 n 一定在角落 → f^λ=Σ_角落 f^{λ−c}；(3,2)：f^{(2,2)}+f^{(3,1)}=2+3=5。
化約：只需證 Σ_c (1/n)H(λ)/H(λ−c)=1；(3,2)：(1/5)(24/12)+(1/5)(24/8)=2/5+3/5=1。

**M14 `sceneM14_hook_walk.py` / `SceneM14HookWalk`（L4，~2.5–3 分鐘，分段）**
用模組層級函式 `part1_walk(scene)` … `part5_conclusion(scene)`（不可寫成場景的方法，見第 6 節），每段結束清空畫面：
1. 鉤上漫步：均勻選起點格（機率 1/n），每步跳到目前格子鉤上的其他格（機率 1/(h−1)），只往右／往下 → 停在角落。示範一次。
2. 主張 P(c)=(1/n)·H(λ)/H(λ−c)；因為一定停在某個角落，ΣP(c)=1，正好是 M13 的化約 → 鉤長公式（對 n 歸納）。
3. 一條路徑的機率 = (1/n)∏1/(h(a_i)−1)；把路徑投影成經過的列集合 A、行集合 B。
4. 關鍵恆等式（c=(α,β) 是角落）：h(a,b)−1 = (h(a,β)−1)+(h(α,b)−1)；引理：從 (a,b) 出發、列集合 A、行集合 B 的所有路徑權重和 = ∏_{i∈A∖{α}} 1/(h(i,β)−1) · ∏_{j∈B∖{β}} 1/(h(α,j)−1)（對 |A|+|B| 歸納，第一步往下或往右）。
5. 對所有起點與 A、B 加總：P(c) = (1/n)∏_{i<α}(1+1/(h(i,β)−1))∏_{j<β}(1+1/(h(α,j)−1)) = (1/n)∏ h/(h−1) = (1/n)H(λ)/H(λ−c)（拿掉 c 只讓 c 上方與左方的格子鉤長各減 1）。
數值驗算 (3,2)：P(角落 (1,3))=2/5、P((2,2))=3/5（程式用精確分數列舉所有漫步算出）。

## 6. 實作規則（給寫場景的 AI）
- 參考寫法：`codes/scenes/scene00h_balanced_parentheses.py`（短）、`scene00k_one_number_many_objects.py`（多物件排版）。
- 繼承 `utils.scene_base.ChuScene`：`show_header(text)`、`say(*parts)`（以 `$` 開頭的段是 LaTeX，其餘中文）、`clear_stage()`、`fade_all()`。
- 文字：中文用 `utils.styles.zh()`／`mixed()`（中文不可放進 Tex）；重點框 `boxed()`（黃）。
- 顏色：一般卡塔蘭物件 BLUE（`catalan_draw.CATALAN_COLOR`），根 ORANGE、左 TEAL、右 PINK（`catalan_draw.PART_COLORS`），不合法 RED。
- **輔助函式一律寫成模組層級的函式**（連續播放會用別的場景物件呼叫 `construct`，場景自己的方法會找不到）。
- 數學資料一律由 `utils/counting.py` 算，畫面上出現的數字都要 `assert`。
- Tex：字串開頭／結尾不可有 `\;`、`\,`；`Tex("a","b")[1]` 是第 2 個字形不是第 2 段；上色用 t2c 時整個因子一起上色。
- 畫面範圍：x∈[−6.8,6.8]、y∈[−3.0,3.2]（底部是字幕、左上是標題）；擁擠的地方用 assert 檢查不出界、不重疊。
- **只建立自己的場景檔**；不要改既有場景、`counting.py`、`catalan_draw.py`、`mit_draw.py`、`styles.py`、`scene_base.py`、`main.py`、`render_all.py`、README、交接說明。共用工具有問題就在自己的檔案裡繞過並回報。
- 驗證：用工作工具 `mit_render.py`（路徑由派工訊息提供）輸出低畫質到暫存資料夾，它會用嚴格 LaTeX 模式（編譯失敗會報錯）並產生總覽圖；看總覽圖修排版，再重跑。不要輸出到 `codes/renders/`。
