## L1 卡塔蘭數
- 定義：e_i∈{+1,−1}，Σe_i=0、每個前綴和≥0 → Dyck 路徑（+1=↗，−1=↘）。C_0..C_5=1,1,2,5,14,42。
- C_n = 凸 (n+2) 邊形三角剖分數（五邊形 5 種）。先證兩者滿足同一遞迴，尚未給一一對應。
- 第一次回到地面：P = U P₁ D P₂ → C_n=Σ_{k=1}^{n} C_{k−1}C_{n−k}=Σ_{k=0}^{n−1}C_kC_{n−1−k}（一個物件 → 兩個獨立的小物件）。
- 生成函數 C(x)=ΣC_n xⁿ；Cauchy 乘積 [xⁿ]C²=Σ_{k=0}^{n}C_kC_{n−k} → C−1=xC² → C=1+xC²（獨立相乘 ↔ 生成函數相乘）。
- xC²−C+1=0 → C=(1±√(1−4x))/(2x)，C(0)=1 取減號；二項級數展開 → C_n=(1/(n+1))·binom(2n,n)。
- 醉漢走路（對稱隨機漫步，懸崖）：L1 提出，L2 完成。

## L2 反射原理、循環移位
- 醉漢最後一定掉下懸崖：機率 1（用卡塔蘭數列出「第一次到懸崖」的路徑，再用生成函數加總）。
- 反射：(0,0)→(2n,0) 的 ±1 路徑共 binom(2n,n)；壞路徑 = 碰到 y=−1；把「起點到第一次碰到 y=−1」那段對 y=−1 反射 → 壞路徑 ↔ (0,−2)→(2n,0) 的路徑，共 binom(2n,n−1)。C_n=binom(2n,n)−binom(2n,n−1)。
- 循環移位（cycle lemma 類）證明 C_n=(1/(n+1))binom(2n,n)；與 Chu 講義的 Raney／循環引理同一類方法。
- 其他詮釋：三角剖分、括號化、平面二元樹、完全平面二元樹。括號 ↔ 上下步的對應要驗證是單射＋滿射。

## L3 一一對應、排序、分割
- 平面樹（n+1 個頂點，小孩有左右順序）有 C_n 棵；n=3 有 5 棵。
- 線上 2n 點的弧圖：不交叉（禁止 i<j<k<l 的 (i,k),(j,l)）與不巢狀（禁止 (i,l),(j,k)），兩者都是 C_n。
- 三角剖分 ↔ 完全平面二元樹：對偶圖（三角形=節點、共用對角線=邊，邊界加葉子／根）。
- 平面樹 ↔ Dyck：深度優先走訪，往下=U、往上=D；n 條邊 → 2n 步。
- Dyck ↔ 不交叉配對：每個 U 和它配對的 D 連一條弧。
- 鏈：三角剖分 ↔ 二元樹 ↔ Dyck ↔ 不交叉配對。
- 堆疊排序（LIFO）：231 無法排序。佇列（FIFO）＋插隊線（bypass）的排序模型。
- 模式：w 含 π ⇔ 有子序列和 π 的相對大小相同；否則 π-avoiding。
- 定理：可用堆疊排序 ⇔ 避開 231，個數 C_n；避開任一個長度 3 的模式都是 C_n 個。
- 整數分割 λ=(λ₁≥…≥λ_k>0)，Σ=n；有順序的叫合成（composition）。Young 圖（例 (5,3,3,2,1)）。
- 標準 Young 表 SYT：填 1..n，每列由左到右、每行由上到下都遞增；f^λ = SYT 個數。

## L4 Young 表、鉤長公式
- f^λ 是對稱群不可約表示的維數。f^{(n,n)} = C_n。
- SYT(n,n) ↔ Dyck：i 在第一列 → 第 i 步 U，第二列 → D（行遞增 ⇒ 不低於地面）。
- 一般 λ：i 在第 r 列 → 走 e_r，得到 k 維格子路徑，停在 Weyl chamber 類區域內。
- 鉤 hook(c)=c 自己＋同列右邊＋同行下面；鉤長 h(c)=格數。
- 鉤長公式（Frame–Robinson–Thrall）：f^λ = n!/∏_{c∈λ} h(c)。
- 角落遞迴：n 一定在角落 → f^λ=Σ_{角落 c} f^{λ−c}。
- 只需證 Σ_c (1/n)·H(λ)/H(λ−c) = 1，其中 H(λ)=∏h(c)。
- 鉤上漫步（hook walk）：均勻隨機選起點格；每步跳到目前格子鉤上的其他格（均勻）；只往右／往下 → 必停在角落。
- P(c)=停在角落 c 的機率；路徑權重＝每一跳機率的乘積；用矩形區域的加權路徑引理（對矩形大小歸納）加總。
- P(c) = (1/n)·∏_{b 在 c 的同列左邊或同行上面} h(b)/(h(b)−1) = (1/n)·H(λ)/H(λ−c)（拿掉 c 只讓這些格的鉤長各減 1）。ΣP(c)=1 → 鉤長公式。

## 與 Chu 的關係
- 最直接的是 Dyck ↔ 不交叉配對，以及 C=1+xC²。Chu：每組 2 點 → 指定大小 v_i；根產生 v_i 個子問題 → D=1+Σx_iD^{v_i}。
- 術語：L3–4 的 partition 是整數分割；Chu 的 partition 是集合分割成區塊，兩者不同。L1–4 沒有發展一般的不交叉集合分割理論。
