## 運算式、前序記法與字


### 運算式、前序記法與字 1

**題。** 運算式 `T(U(a,b,c),d,e)` 的前序寫法與型是什麼？是字嗎？

**解。** 前序寫法 `TUabcde`，型 `3300000`。開頭的秩依序是 0, 2, 4, 3, 2, 1, 0, -1：最後一項才第一次到 −1，所以是字（Rosenbloom 判別法）。組成 (1; 0, 0, 2)，引數 a₀ = 5 個，長度 m = 7。

## 循環引理（定理 2.1）與 Raney 的證明


### 循環引理（定理 2.1）與 Raney 的證明 1

**題。** 字串 σ = `300000300` 的秩是多少？哪些 k 使 σg_k 是字列？照 Raney 的證明走一遍。

**解。** r(σ) = -3，所以 n = 3。好的 k = [4, 5, 6]。秩最大（同秩取最長）的一段 α = `3003`（秩 2），從它開始讀 σ₁ = σg_6 = `300300000` = `3003000 | 0 | 0`；輪換這 3 個字得到全部 3 個字列。

**題。** 解 w = x·φ(w)，φ(x) = 1 + x + 2x^2 + x^3。前 6 項係數？

**解。** 由 Lagrange 反演 [xⁿ]w = (1/n)[xⁿ⁻¹]φⁿ（= 所有 n 個節點的平面樹的權重和）：1, 1, 3, 8, 25, 81（逐次代入解方程得到相同的數）。

## 卷積（Gould、Hagen–Rothe）


### 卷積（Gould、Hagen–Rothe） 1

**題。** 驗證 Hagen–Rothe（Raney (7.8)，γ = 1）：α₁ = 1、α₂ = 1/3、β = 3、n = 2。

**解。** G(α₁+α₂, n) = 38/9；右邊 Σ G(α₁,k)G(α₂,n−k) = 8/9 + 1/3 + 3 = 38/9。取 α 為正整數 t、β = v 時就是 Chu 的 A_t((n),(v))。

## 整數序列的 Raney 引理


### 整數序列的 Raney 引理 1

**題。** x = (1, 3, -3, -3, 3, 0)（總和 1）。哪一種循環讀法出發後高度都 > 0？各讀法有幾個正的點？

**解。** 高度 [1, 4, 1, -2, 1, 1]，最後一個最低點在第 4 點，所以從第 4 點開始讀。從第 0..5 點讀的正點數是 [5, 2, 1, 3, 6, 4]（1..6 各一次）。

## 摸牌遊戲


### 摸牌遊戲 1

**題。** 摸牌遊戲（洛谷 P6672）：w = (1, 2, 2)、m = 5，牌都有標號。幾種排法能摸到勝利牌？

**解。** m!/(m−n+1) = 120/3 = **40**（窮舉也是 40）。合格的牌序加上勝利牌就是一個 Raney 的字。
