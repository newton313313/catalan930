# 2. Very important mathematical naming/indexing rules

Be stricter than the source paper when presenting indexing.

Use this convention consistently:

\[
\boxed{
C_n=\frac1{n+1}\binom{2n}{n}.
}
\]

Then explicitly state the standard correspondences as follows.

### Polygon triangulation

Number of triangulations of a convex polygon with \(m\) vertices:

\[
\boxed{C_{m-2}}.
\]

Equivalently, a convex \((n+2)\)-gon has

\[
\boxed{C_n}
\]

triangulations.

The source explicitly states \(C_n=T_{n+2}\). aybeyan-pdf

Prefer saying:

> “A convex \((n+2)\)-gon has \(C_n\) triangulations.”

because this aligns every later animation directly with \(C_n\).

---

### Fully parenthesized products

For \(n+1\) ordered factors

\[
a_0a_1\cdots a_n,
\]

the number of full binary parenthesizations is

\[
\boxed{C_n}.
\]

The source gives the concrete cases of 2, 3 and 4 factors, with the 4-factor case having five possible multiplication orders. aybeyan-pdf

---

### Full binary trees

Use the precise statement:

> The number of **full plane binary trees with \(n\) internal vertices** is \(C_n\).

If the existing project uses another binary-tree convention, explicitly say what is being counted.

Do not casually say only “binary trees with \(n\) vertices = \(C_n\)” because different conventions shift the indexing.

The source discusses binary and planted trivalent binary trees and their bijection with triangulations. aybeyan-pdf

---

### Lattice paths

Number of monotone paths from

\[
(0,0)\rightarrow(n,n)
\]

using

\[
R=(1,0),\qquad U=(0,1)
\]

that never go above

\[
y=x
\]

is

\[
\boxed{C_n}.
\]

The source first counts all paths as

\[
\binom{2n}{n}
\]

and gives the valid count as

\[
\binom{2n}{n}
-
\binom{2n}{n-1}
=
C_n.
\]

aybeyan-pdf

---

### Dyck paths

Use the standard convention:

A Dyck path of semilength \(n\) consists of \(n\) up-steps and \(n\) down-steps and never falls below its starting height.

Number:

\[
\boxed{C_n}.
\]

The supplied article explicitly gives:

\[
n=0:1,\qquad
n=1:1,\qquad
n=2:2,\qquad
n=3:5.
\]

It also connects up/down steps with opening/closing parentheses. aybeyan-pdf

---

### Noncrossing perfect matchings

For the bridge to Chu:

> Number of noncrossing perfect matchings of \(2n\) labeled cyclically ordered points is

\[
\boxed{C_n}.
\]

This is the classical Motzkin interpretation used in the Chu paper.
